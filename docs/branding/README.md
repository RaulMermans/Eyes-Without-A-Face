# Branding

## Provenance

The official emblem is the **Neon Cyber-Angel Eye Emblem** supplied by the project owner (Raul) for Eyes Without a Face. It is a square transparent RGBA PNG of the original artwork. This repository does not redraw or restyle that mark.

Source file used in Sprint 1: the owner-supplied PNG imported into `src/assets/brand/eyes-emblem-original.png`.

## Files

| File | Use |
| --- | --- |
| `src/assets/brand/eyes-emblem-original.png` | Archival original (transparency preserved) |
| `src/assets/brand/eyes-emblem.webp` | Landing / large UI |
| `src/assets/brand/eyes-emblem-small.png` | Header (40×40 CSS, square) |
| `public/favicon.png` | Favicon 32×32 |
| `public/favicon-48.png` | Favicon 48×48 |
| `public/apple-touch-icon.png` | 180×180 on navy (no transparency) |
| `public/og-image.png` | Social-preview foundation |

The interface uses navy, restrained violet, and selective gold so the emblem stays the distinctive element. Workspace headers keep the mark small; the source landing uses the larger treatment.
